# سجل التغييرات والتدقيق — لَوح 1.1.0

## النطاق والقيود
- التطبيق يبقى محلياً وأوفلاين؛ لم تُضف أذونات أو اتصالات شبكة أو تحليلات.
- لم تُعدّل أي ملفات داخل assets/ أو scripts/build_quran_data.py.
- لم يتغير معرّف الحزمة com.bazzo.lawh ولا منطق التوقيع.
- مجلد android/ لا يُضاف إلى المستودع ويستمر توليده في GitHub Actions.

## تدقيق الحالة السابقة
- شاشة الكتابة تستخدم TextField شفافاً فوق QuranPageView؛ هذا يفسر ظهور النص المكتوب في أعلى/وسط الصفحة بدلاً من موضع الكلمة المطبوعة.
- qcf_quran_plus يعرض الصفحات من تخطيط QCF مُسبق وخط خاص بكل صفحة، ويتيح WordHighlight وonWordTap، لكنه لا يوفّر عبر واجهته العامة مستطيل Rect لكل كلمة.
- بناء TextPainter مستقل من نص الآيات لا يضمن تطابق الأسطر أو أشكال الحروف أو مواضع ميداليات نهاية الآية مع محرك QCF. لذلك لم أضف محاذاة وهمية؛ الحل الدقيق يتطلب توسيع محرك QCF لإخراج word rects أو تضمين fork مضبوط منه.
- TextNormalizer السابق لم يوحّد waw-hamza وyeh-hamza والهمزة المفردة بشكل صريح.
- تتابع الأيام كان يعتمد على فرق الساعات بين منتصف الليلين، ما قد يتأثر بتغير التوقيت الصيفي.
- اختبار Flutter كان غير حاجب للبناء بسبب continue-on-error.
- يوجد .github/workflows/build.yml وهو الـ workflow الفعّال. النسختان root build.yml وworkflows/build.yml مكررتان/غير فعالتين. ملف توليد مفتاح التوقيع كان داخل workflows/ بدلاً من .github/workflows/.

## المنفّذ في هذه الدفعة
- رفع version إلى 1.1.0+1.
- إضافة هدف يومي افتراضي 10 آيات، مع عداد محلي وحلقة تقدّم وإمكانية تعديل الهدف (1–500).
- إصلاح حساب التتابع ليقارن أيام التقويم بدلاً من عدد فترات 24 ساعة.
- تحسين تطبيع الهمزات وحروف الألف، وإضافة تحويل الأرقام العربية/الهندية إلى أرقام ASCII.
- تحسين بحث السور ليطبع الاسم ويتعرف على الأرقام العربية والهندية.
- إضافة انتقالات RTL (fade + slide) مع احترام MediaQuery.disableAnimations.
- جعل flutter analyze وflutter test خطوات حاجبة في Workflow.
- نقل Workflow إنشاء مفتاح التوقيع إلى المسار الذي يتعرف عليه GitHub Actions، وحذف النسخ المكررة من build workflow.

## تدقيقات ومخاطر ما زالت تحتاج دفعة مستقلة
- محاذاة الكتابة فوق مواضع كلمات QCF بدقة: غير منفذة بعد؛ يلزم استخراج Rect من محرك QCF نفسه واختبار widget حقيقي.
- سجل مراجعة متباعدة 1/3/7 أيام: لم يُنفّذ بعد.
- اختبار حسب الحزب والصفحة: لم يُنفّذ بعد.
- ملخص الجلسة مع أبطأ كلمة ومشاركة النص: لم يُنفّذ بعد.
- تصدير/استيراد JSON: لم يُنفّذ بعد.
- الاهتزاز والأصوات الاختيارية: لم تُنفّذ بعد.
- شاشة الترحيب والإعدادات الموسعة: لم تُنفّذ بعد.
- إعادة تصميم Home بالكامل وHero/staggered animations: لم تُنفّذ بعد؛ تمت إضافة بطاقة الهدف فقط.
- التحقق على جهاز Android فعلي غير ممكن من بيئة GitHub Actions وحدها.

## القرارات
- لا نضيف حزماً جديدة في هذه الدفعة.
- لا نعدّل نص القرآن أو بيانات السور لتصحيح أخطاء العرض.
- لا نستخدم TextPainter موازياً لمحرك QCF ونزعم أنه مطابق دون قياس فعلي.
- الاختبارات الآن تمنع البناء عند الفشل، بدلاً من إخفاء الفشل.
